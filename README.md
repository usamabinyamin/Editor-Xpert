# Editor Xpert

Marketing website for **Editor Xpert** — YouTube automation, video editing, thumbnails, publishing, and channel growth.

Built with **React**, **Vite**, **Tailwind CSS**, and **Framer Motion**.

## Local development

```bash
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173).

## Production build

```bash
npm run build
npm run preview
```

## GitHub

Repository: [github.com/usama1088/editor-xpert](https://github.com/usama1088/editor-xpert)

After pushing to `main`, enable **GitHub Pages** (Settings → Pages → Source: **GitHub Actions**). The site will be published at:

**https://usama1088.github.io/editor-xpert/**

## First-time push (if the repo is new on GitHub)

1. Create an empty repo at [github.com/new](https://github.com/new) named `editor-xpert` (do not add a README).
2. Run:

```bash
git remote add origin https://github.com/usama1088/editor-xpert.git
git branch -M main
git push -u origin main
```
